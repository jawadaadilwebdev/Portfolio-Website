# 💼 Personal Portfolio Website

A modern, responsive portfolio website built with **React.js** and **Tailwind CSS** to showcase my skills, projects, and experience as a **Full Stack MERN Developer**. The website serves as my personal brand, highlighting my technical expertise, featured projects, and contact information for recruiters, clients, and collaborators.

---

## 🚀 Live Demo

🌐 **Portfolio:** *(https://jawad-aadil-dev.vercel.app/)*

* 👋 Hero section with introduction
* 👨‍💻 About Me section
* 🛠️ Technical Skills showcase

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/jawadaadilwebdev/Portfolio-Website.git
```

Navigate into the project directory

```bash
cd Portfolio-Website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Visit

```text
http://localhost:5173
```
